# AttendEase – Smart Student Attendance Management System

## 1. Project Title

**AttendEase – Smart Student Attendance Management System**

AttendEase is a simple and user-friendly web-based application designed to manage student attendance digitally.

## 2. About the Project

AttendEase is a Student Attendance Management System developed using HTML5, CSS3, and JavaScript.

The main purpose of this project is to make student attendance management easier, faster, and more organized. Instead of maintaining attendance records manually in registers, teachers or users can use this website to add students, mark attendance, search student records, and view attendance reports.

The application uses the browser's Local Storage to save student information and attendance records. This allows the data to remain available even after refreshing or reopening the browser on the same device.

This project is developed as an academic project to demonstrate frontend web development concepts and practical JavaScript implementation.

## 3. Features

- **Add New Students:** Add students with their names and roll numbers.
- **Duplicate Roll Number Validation:** Prevents adding students with an existing roll number.
- **Mark Attendance:** Mark students as Present or Absent.
- **Date-Wise Attendance:** Manage attendance records for different dates.
- **Mark All Present:** Mark all listed students as present with one action.
- **Search Students:** Search students by name or roll number.
- **Attendance Percentage:** Calculate individual student attendance percentages.
- **Attendance Reports:** View attendance summaries and reports.
- **Clear Attendance:** Clear attendance records for a selected date.
- **Data Persistence:** Save student and attendance information using Local Storage.
- **Responsive Design:** Access the website on desktop, tablet, and mobile screens.

## 4. Technologies Used

The project is developed using the following technologies:

### HTML5
- Used to create the structure of the website.
- Uses semantic HTML elements.
- Creates forms, tables, buttons, and content sections.

### CSS3
- Used to design and style the website.
- Uses Flexbox and CSS Grid for layouts.
- Includes responsive media queries.
- Provides a clean and user-friendly interface.

### JavaScript (ES6+)
- Used to implement website functionality.
- DOM manipulation for dynamically updating content.
- Event listeners for handling user interactions.
- Functions and arrays for managing student records.
- Template literals for generating dynamic content.

### Browser API
- **Local Storage API:** Stores student details and attendance records in the browser.
- **DOM API:** Updates webpage content dynamically.

## 6. How to Run

Follow these steps to run the project:

1. Download or clone the project repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Install the Live Server extension in VS Code (if not already installed).
5. Right-click on `index.html`.
6. Select **Open with Live Server**.
7. The AttendEase website will open in your default web browser.

**Alternative:** You can also open the `index.html` file directly in a web browser.

## 7. How to Use

Follow these steps to use the AttendEase application:

1. Open the AttendEase website in your browser.
2. Add a new student by entering the student's name and roll number.
3. View the added students in the student list.
4. Select the required attendance date.
5. Mark each student as Present or Absent.
6. Use the Mark All Present option to mark all students present.
7. Use the search feature to find a student by name or roll number.
8. View individual attendance percentages and attendance reports.
9. Use the Clear Attendance option to clear records for the selected date.

**Note:** Attendance data is stored in the browser's Local Storage. It is available on the same browser and device where the data was saved. It is not automatically shared between different users or devices.
